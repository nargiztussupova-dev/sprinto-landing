# Лендинг Sprinto — статика, без сборки

Сайт на русском языке: квиз из 4 вопросов подбирает формат занятий, кнопки ведут в Telegram-бот, WhatsApp и (если задана ссылка) на оплату.

## Что внутри

| Файл | Зачем |
| --- | --- |
| `index.html` | Страница: 9 блоков и квиз |
| `config.js` | **Контакты, Pixel ID, цены, ссылки на оплату** |
| `content.json` | **Все тексты и отзывы** |
| `quiz-logic.js` | Правила подбора продукта (9 правил) |
| `quiz.test.js`, `quiz-test-results.md` | Тест правил и таблица прогонов |
| `analytics.js` | UTM, пиксель Meta, Яндекс Метрика, события |
| `app.js`, `styles.css` | Вёрстка и логика |
| `mascot.webp`, `favicon.png`, `apple-touch-icon.png`, `og.jpg` | Маскот, иконки, превью для соцсетей |

## Что заполнить в `config.js`

- `telegramBotUrl` — ссылка на бот, **только вида `https://t.me/имя_бота`**. Пока она пустая или другая, кнопки Telegram нет, основной остаётся WhatsApp.
- `whatsappUrl` — ссылка-сообщение WhatsApp Business (`https://wa.me/message/…`). Если её нет, заполните `whatsapp` (номер без плюса).
- `whatsappPrefill` — `true` добавит к ссылке текст «Хочу записаться: …»; включайте только после проверки, что WhatsApp его принимает.
- `telegramStartParam` — `true`: ссылка на бот получает `?start=<продукт>` (например `/start marathon`, `/start intensive_two_months`), и бот может понять, какую кнопку нажали. Работает, только если бот это обрабатывает.
- `products` → `payUrl` — ссылка на оплату продукта. Если заполнена, у продукта появляется основная кнопка «Оплатить», а Telegram и WhatsApp остаются ссылками под ней. У интенсива две ссылки: стандартный доступ и 2 месяца. Если пусто — кнопки «Записаться».
- `metaPixelId`, `yandexMetrikaId` — аналитика.
- `policyUrl`, `offerUrl` — необязательны; пустые ссылки скрывают пункты в подвале.

## Тексты и отзывы (`content.json`)

Правьте тексты внутри кавычек, не трогая запятые и скобки. Отзывы лежат в `reviews.items`, формат `{ "name": "Имя, продукт", "text": "…" }`. Список пустой — блок скрыт. Отзыв Жансаи оставлен на казахском, как его написали; при желании удалите его из списка.

## События

| Событие | Когда | Параметры |
| --- | --- | --- |
| PageView | загрузка страницы | — |
| ViewContent | раскрыта карточка или показан результат квиза | продукт, цена |
| QuizComplete (своё) | последний ответ квиза | ответы, рекомендованный продукт, правило |
| Lead | клик «Записаться» (Telegram или WhatsApp) | продукт, `method` = telegram / whatsapp |
| InitiateCheckout | клик «Оплатить» (только если задан `payUrl`) | продукт, цена, `currency = KZT` |

UTM-метки сохраняются при входе и добавляются ко всем событиям. Для рекламы оптимизируйте кампанию на **Lead**. Оплата проходит вне сайта, поэтому покупки (Purchase) здесь не фиксируются.

В Метрику (если подключена) уходят те же цели плюс `quiz_start` и `quiz_step_1…4`: видно, где бросают квиз.

## Проверка локально

`python -m http.server 8000` в папке проекта → http://localhost:8000 (двойной клик по `index.html` не сработает: браузер блокирует загрузку `content.json`).

`node quiz.test.js` — 16 прогонов правил квиза должны быть зелёными.

## Открытые вопросы по квизу

В правилах есть сочетания, которые попадают в «всё остальное → Челлендж»:
- «Учил(а), забросил(а)» + «попробовать за неделю»;
- «Учил(а), забросил(а)» + «с группой 2 недели»;
- «Пара фраз» + «Интенсив».

Если нужно другое поведение, правится в `quiz-logic.js` и `quiz.test.js`.
