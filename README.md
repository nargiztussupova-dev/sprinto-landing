| Файл | Зачем |
| --- | --- |

## Что заменить перед запуском

1. `config.js`: `metaPixelId`, `whatsapp`, `telegramBotUrl`, `policyUrl`, `offerUrl`, ссылки `kaspi` у всех 8 тарифов (пустая ссылка = кнопка ведёт в WhatsApp с текстом «Хочу оплатить …»). Если нужен счётчик Метрики — `yandexMetrikaId`.
2. `content.json`: **тексты — заглушки**, замените текстами Кристины. Отзывы тоже заглушки — не публикуйте как есть. Казахская версия набросана автоматически, её нужно вычитать носителю.
3. Картинки в папку `assets/`: `mascot.webp` (маскот, пока вместо него оранжевый круг), `og.jpg` (1200×630), `favicon.png` (маскот; сейчас в `<head>` стоит заглушка-иконка). Видео демо: путь в `config.js` → `demo.video`.
4. `index.html` и `thanks.html`: реквизиты ТОО в `content.json` → `footer.requisites`; мета-тег верификации домена Meta — вставить на место закомментированной строки в обоих файлах.

## Запуск на Render (бесплатный Static Site)

**Важно:** в репозитории `sprinto-site` уже лежат `index.html`, `test.html`, `go.html` (QR на напечатанных брошюрах ведёт на `go.html`). Файлы этого лендинга **не копируйте поверх него** — `index.html` затрётся. Создайте отдельный репозиторий, например `sprinto-landing`.

1. GitHub → New repository `sprinto-landing` → загрузите все файлы из архива (ветка `main`).
2. Render → New + → **Static Site** → выберите репозиторий.
3. Build Command: оставить пустым. Publish Directory: `.`
4. После деплоя откройте адрес `*.onrender.com` и проверьте страницу.
5. Render → сервис → Settings → **Custom Domains** → Add → `start.sprinto.kz`.
6. В DNS домена `sprinto.kz` (доступ даёт Кристина) создайте запись **CNAME**: имя `start`, значение — адрес `*.onrender.com`, который показал Render.
7. Дождитесь «Verified», HTTPS выпустится автоматически.

Проверка локально: `python -m http.server 8000` в папке проекта → http://localhost:8000 (двойной клик по `index.html` не сработает, браузер блокирует загрузку `content.json`).

## Страница «Спасибо»

Адрес: `https://start.sprinto.kz/thanks.html?product=marathon`. Допустимые значения `product`: `challenge`, `marathon`, `app_a2`, `intensive`, `individual`, `group_online`, `songs`. Для интенсива на 2 месяца добавьте `&variant=two_months`. Если Kaspi не умеет возвращать на свой адрес, Кристина отправляет эту ссылку после оплаты вручную.

Purchase уходит один раз за сессию на продукт и только если `product` указан верно (иначе события нет, чтобы не искажать данные). Открытая кем-то ссылка тоже засчитается как покупка — это ограничение схемы из ТЗ, снимается через Conversions API на втором этапе.

## События

| Событие | Когда | Параметры |
| --- | --- | --- |
| PageView | загрузка страницы | — |
| ViewContent | раскрыта карточка или показан результат квиза | `content_name`, `value`, `currency`, `source` |
| Lead | последний ответ квиза | ответы, рекомендованный продукт, правило |
| InitiateCheckout | клик «Оплатить» | `content_name`, `value`, `currency = KZT` |
| Contact | клик «Оплатить через WhatsApp» и «Написать в WhatsApp» | `method` |
| Purchase | открыта «Спасибо» | `content_name`, `value`, `currency = KZT` |

UTM (`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`) сохраняются при входе и добавляются ко всем событиям. Чтобы добавлять их ещё и к ссылке Kaspi, включите `appendUtmToKaspi: true` в `config.js` — только после проверки, что Kaspi их принимает. В Метрику (если подключена) уходят те же цели плюс `quiz_start` и `quiz_step_1…5`, чтобы видеть, где бросают квиз.

Казахская версия: `https://start.sprinto.kz/?lang=kz` — отдельный адрес для рекламы без второго домена.

## Вопросы к Кристине (дыры в правилах квиза)

В правилах из ТЗ есть сочетания, которые попадают в «всё остальное → Челлендж», хотя, возможно, должны вести в другое место:

- «Учил(а), забросил(а)» + «попробовать за неделю»;
- «Учил(а), забросил(а)» + «с группой 2 недели»;
- «Пара фраз» + «Интенсив» (правило есть только для «с нуля» и «забросил(а)»).

Если нужно другое поведение, правится в `quiz-logic.js` (одна функция) и в `quiz.test.js`.

## Проверка перед приёмкой

`node quiz.test.js` — все 16 прогонов должны быть зелёными (таблица в `quiz-test-results.md`). Остальное по чек-листу ТЗ: iPhone и Android во встроенном браузере Instagram, Events Manager → Test Events, PageSpeed Insights (мобильный).
